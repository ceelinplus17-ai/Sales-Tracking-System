Woodstock Yarn Shop - Snoopy Sales Tracking System (PHP + MySQL + JS, XAMPP)

1. Start Apache and MySQL in XAMPP.
2. Copy the whole 'yarnshop' folder into C:\xampp\htdocs\yarnshop (including the 'assets' folder).
3. Open http://localhost/phpmyadmin > Import > choose database.sql > Go.
4. Open http://localhost/yarnshop/index.php and sign in to start tracking sales!
